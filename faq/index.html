训练与研究

96题训练器会把我的答题记录上传服务器吗？

不会。进度保存在当前浏览器 localStorage；可手工导出/导入JSON备份。训练器不调用AI，不产生API成本。详见 互动训练器。

Market Lab里的真实案例是在给交易信号吗？

不是。案例用于研究规则、漏信号、假突破、持仓管理和EA状态机。历史结果不能代表未来，同类结构也不保证重复。

为什么网站会保留失败策略和漏信号？

因为只展示成功样本会让研究失真。T5把失败项目、错误触发、漏信号和正确过滤都作为审计证据，样本簇才推动规则修改。

免费源码体检

免费源码体检会上传我的源码吗？

不会。高级体检使用浏览器 File API 在本地读取源码；免费扫描和本地交接都被CI合同限制，不能调用 /api/*、fetch、XHR或FormData上传。

支持哪些源码？

当前公开入口支持 .mq4、.mq5、.pine 和文本源码，单文件上限512 KB。体检可以识别平台、主要模块、明显风险和修改影响，但不运行EA、不回测。

免费体检已经看过源码结构，为什么还需要AI深度分析？

静态扫描只能识别代码特征；AI阶段才用于重建函数/变量调用关系、Entry/Exit/Risk/State语义、冲突和本次冻结修改范围。详见 免费体检 vs AI深度分析。

体检后进入Builder要重新选择文件和重写要求吗？

当前浏览器会话内可以直接交接，源码和修改要求暂存在sessionStorage，有效期约2小时。它仍然不是服务器上传；真正点击付费AI上传时才进入后端。

Builder Pass、付款与退款

Builder Pass现在是什么价格？

首发为 $14.90 / 30天，包含3次AI深度源码分析和2次完整源码修改，不自动续费。实际结账以 Checkout 显示和支付配置为准。

未付款会不会偷偷调用OpenAI？

不会。上传、Analyze、Modify 都必须先通过付费Grant门禁；没有有效权限时请求会在OpenAI调用前被阻止。

什么时候可以退款？

如果付费AI服务尚未成功执行，可按公开规则申请退款；一旦AI深度分析或源码修改已成功执行，数字服务已经开始履约，不提供普通无理由退款。系统故障、法律或支付机构规则另有要求的除外。详见 退款政策。

PayPal争议期间还能继续使用AI额度吗？

不能。争议创建后相关Grant会暂停；争议取消或卖家胜诉后可恢复，退款或买家胜诉则撤销对应权限。

源码修改与验证边界

AI修改能保证原算法百分之百不变吗？

不能靠承诺证明。正确流程是先重建现有逻辑、冻结“要改/不改”范围，再生成完整修改版和CHANGELOG，最后通过编译、逐笔审计、跨平台Parity和前向验证确认。

EA编译通过就能实盘了吗？

不能。编译只证明语法/类型层面可构建，不证明订单返回、持仓状态、部分平仓、保本、重启恢复、点差和经纪商差异都正确。可查看 EA能编译为什么还不能实盘。

可以帮我反编译EX4/EX5或绕过第三方授权吗？

不提供。只处理用户拥有或已获授权的源代码，不做EX4/EX5反编译、破解、移除许可证、绕过第三方授权或窃取源码。

T5 Quant Lab能保证策略盈利吗？

不能。本站提供学习、软件研究、训练、源码工程和验证工具，不提供收益保证、资金管理、代客操盘或个性化投资建议。
