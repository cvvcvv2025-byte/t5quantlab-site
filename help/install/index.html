Windows：使用包内辅助安装工具

  1. 把专属 ZIP 完整解压到一个文件夹。
  2. 双击 Install-Windows.cmd。
  3. 在 MT 点“文件 → 打开数据文件夹”，再在安装工具弹出的窗口里选择同一个数据文件夹。

③ 新开图表，
加载本产品的 T5 模板。

安装后刷新 MT 导航器。在新的空白图表上右键 → 模板，选择安装说明指定的 T5 模板。模板会一起加载指标和授权服务，无需填写产品码或激活密钥。

同产品的其他周期图表：只加载指标即可
不要把模板应用到已有交易 EA 的图表。
一个图表只能挂一个 EA，加载模板可能替换原 EA。请新开空白图表，并保留这个模板图表。不同产品分别加载对应模板。

首次从手动密钥升级：请移除同产品旧授权助手，再加载新模板，避免两个授权服务同时运行。原业务图表可以保留。已有专属包再次下载不会更换密钥。

EA 产品怎么用？

EA 不使用指标模板。安装后加载产品自身，授权密钥留空即可读取绑定配置。请自行核对交易参数和自动交易权限；安装工具不会替你开启交易。

重装、换绑和到期

情况处理方式
同一账号重装重新下载原绑定专属包，无需撤销。
改交易账号／服务器撤销旧授权，30 分钟后可重新绑定。既有撤销记录也按原撤销时间＋30分钟计算。
换电脑／终端先退出旧终端，等待旧租约结束；同一授权同时仅一个安装实例。
到期、撤销或断网每分钟联网校验，既有签名租约最多5分钟。过期后指标停用；EA 禁止新增／加仓，仍管理已有持仓。

专属包包含私有授权配置，请勿转发。遇到问题请提供产品、平台和错误提示，不要发送密码、验证码或配置文件。
