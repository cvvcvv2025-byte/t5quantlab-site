BREAK · STAY · RETEST · RECLAIM

判断突破最重要的不是“有没有穿过去”，而是市场愿不愿意留在外面。

Acceptance与Rejection是T5用来区分“真突破延续”和“扫流动性失败”的核心语言。

ACCEPTANCE

接受

价格突破关键位后，实体持续在外侧成交；回踩时原关键位能转化为支撑/阻力，并继续形成顺突破方向的推动。

REJECTION

拒绝

价格越过关键位但无法在外侧停留，快速Reclaim原区域，并开始破坏原突破方向的微结构。

观察顺序

1. Break

先确认是实体突破、收盘突破还是只有影线。程序化前必须冻结标准。

2. Stay

突破后接下来几根K线是否仍在外侧？如果马上回去，所谓突破的可信度快速下降。

3. Retest / Reclaim

第一次回测守住属于Acceptance证据；重新深度进入原区间属于Rejection/Reclaim证据。

4. Follow-through

真正决定执行质量的是后续推动有没有效率，而不是单独一根突破K线有多大。

几个常见误判

现象更合理的解释
长上影穿过前高先视为Sweep候选，不直接定义为突破
大阳线收在前高上方只是Break，后续是否接受仍未确认
突破后横盘在外侧可能是Acceptance，也可能是失去推动；看回踩和后续Follow-through
突破后快速收回并破微结构更接近失败突破/反向接管
回踩关键位时反复上下穿边界尚未形成明确角色转换，降低执行质量

与流动性框架的连接

Sweep + Reclaim：进入反转观察。
Break + Acceptance：进入顺突破回踩观察。
Acceptance后重新深度Reclaim：取消延续路径。
Reclaim后再次在外侧接受：取消反转路径。
