Classic TA / Breakout & Failure
BREAK · ACCEPT · RETEST · RECLAIM · FAILED BREAK

“价格越过一条线”只是事件，不是完整突破。

经典突破交易真正要区分：影线越过、收盘越过、外侧接受、第一次回踩、重新收回，以及突破失败后的反向接管。

突破状态链做Classic TA专项题

突破5阶段

APPROACH进入边界前是压缩、加速、震荡还是单根新闻Spike？
BREAK影线越过还是实体Close越过？突破幅度相对ATR多大？
ACCEPT价格能否继续在边界外侧交易，而不是马上收回？
RETEST第一次回踩是否守住，原阻力/支撑是否角色转换？
FAIL如果重新深度收回，原突破逻辑何时取消？

突破状态链

01 / APPROACH：价格接近边界。压缩接近通常比随机漂移更值得关注，但不决定方向。
02 / BREAK：首次穿越。这里只能说“边界被越过”。
03 / ACCEPT：连续收盘、停留时间或后续位移证明外侧价格被接受。
04 / RETEST：价格第一次回到原边界，观察角色转换。
05 / FOLLOW-THROUGH：回踩守住后重新推进，才完成更成熟的Break-Retest路径。

失败突破不是“噪声”，而是新信息。

WICK ONLY

影线扫过

如果只有瞬间越过，Close重新回到边界内，证据更接近拒绝而不是接受。

RECLAIM

突破后快速收回

原方向没有在外侧建立控制。若随后反向突破攻击者Pivot，失败突破可能升级成反向Setup。

DEEP RETEST

回踩过深

“回踩”不是任何重新进入都算。必须冻结允许深度、Bar数和Close规则。

为什么很多突破策略在回测漂亮、实盘变差？

问题回测里常被忽略实盘影响
触发价格用Close确认，却假设在Break价成交产生未来信息/过好价格
Bid/Ask只看图表中间价实际触发和止损不同
Slippage突破时默认0滑点高速行情入场更差
Gap假设每个价格都可成交止损/突破可能跳价
Retest历史知道哪次是“第一次”状态机没锁定会重复授权

程序化定义示例

break_up = close > level + buffer accept = bars_outside >= 2 AND max_reclaim_depth < tolerance first_retest = break_state==ACCEPTED AND low <= level+zone AND retest_count==0 hold = close > level AND follow_through > min_move failed_break = accepted_or_break AND close < level - fail_buffer

关键不是这组参数是否“标准”，而是所有名词都必须落到Bar、价格、时间和状态。
