PATTERN · NECKLINE · COMPLETION · FAILURE · TOLERANCE

“看起来像”不是形态定义。

任何图表形态都必须拆成可识别部件：Swing、边界、颈线、容差、完成条件、失效与后续。否则只能事后挑漂亮案例。

形态家族做Classic TA专项题

识别形态的6层

SWINGS哪些高低点属于结构节点，而不是普通噪声？
GEOMETRY高度、宽度、斜率、对称度允许多少偏差？
BOUNDARY颈线、三角边界、区间上下沿如何定义？
COMPLETE什么时候形态才真正完成，而不是“正在长得像”？
FAIL什么价格行为直接否定原形态路径？
EXECUTE突破追、第一次回踩、二次拒绝还是微结构确认？

六类常见经典形态

名称不重要，重要的是每一类背后的价格组织方式。

DOUBLE TOP / BOTTOM

双顶 / 双底

两个相近测试 + 中间颈线。第二个高/低点本身不是完成，颈线结果才决定是否进入下一阶段。

看到两个高点就做空 = 提前下注
HEAD & SHOULDERS

头肩顶 / 头肩底

左肩、头、右肩、颈线，以及破位后接受或Reclaim两条路径。

重点：右肩效率 + 颈线结果
TRIANGLE

三角形

对称、上升、下降三角。重点不是名字，而是Swing振幅收窄、边界被多次压缩和突破后的接受。

Compression → Break → Accept
FLAG / PENNANT

旗形 / 旗帜

强位移后短暂逆向或横向整理。要量化整理深度、持续时间和原趋势是否保持。

不是任何小回调都叫旗形
RECTANGLE

矩形 / 箱体

上下边界反复交换，区间中部噪声高，边界反应和突破接受是核心。

Boundary vs Middle
WEDGE

楔形 / 三次推动

推动次数、边界收敛、效率衰减、末端接管。不要只靠两条斜线命名。

Three Pushes / Efficiency

形态最容易被后见之明污染。

EARLY LABEL

过早命名

右肩还没形成、颈线还没定义，就先说“头肩顶”，容易把后续所有K线解释成支持自己。

SUCCESS BIAS

只保存成功图

如果案例库里只有漂亮成功形态，你无法知道实际失败率和模糊边界。

REDRAW

事后重画边界

如果颈线和三角边界可以随结果任意移动，历史识别率没有意义。

程序化识别必须有容差。

对象可量化示例为什么需要
双顶高度|High2-High1| ≤ ATR × tolerance真实市场很少完全等高
间隔min_bars ≤ distance ≤ max_bars避免把相隔过远的Swing硬凑
右肩肩高 / 头高比例区间过滤几何完全失真的形态
三角压缩后续Swing振幅递减不是两条线交叉就叫三角
突破Close outside + min displacement过滤影线扫过
超时pattern_age > max_bars → expire旧形态不能永久等待完成
double_top_candidate = near_equal(high1, high2, ATR*tolerance) completed = close < neckline AND displacement > min_break failed = reclaim_above_neckline OR close > pattern_high expired = bars_since_second_peak > max_age

形态不是方向，它是条件集合。

未完成形态

只能标记“候选”。不应因为名称听起来偏空/偏多就提前授权Entry。

完成但没有Follow-through

颈线破了但无法持续，形态可能快速转为失败突破。

形态目标

测量目标可以作为参考，但不应覆盖前方更近的结构、波动率或流动性约束。

形态与Regime

同一个双顶在强趋势和成熟区间中的统计行为可能不同，不能脱离环境。
