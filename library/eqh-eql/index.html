EQUAL HIGHS · EQUAL LOWS · CLUSTER · SWEEP · ACCEPTANCE

EQH / EQL 的价值不在“绝对相等”，而在同一区域反复留下可见订单聚集。

市场价格很少精确到同一个小数。识别等高等低时，应使用区域和容差，而不是要求多个摆点完全相同。

EQH

Equal Highs

多个可见高点落在相近价格带，常形成明显的上方流动性区域。它可能被Sweep，也可能被真正Break并在上方接受。

EQL

Equal Lows

多个可见低点落在相近价格带，形成下方流动性区域。关键仍是价格到达后发生Rejection还是Acceptance。

不要把EQH/EQL当反转按钮

到达前

只标记Location。此时不能因为“上方有EQH”就直接做空。

穿越后快速收回

进入Sweep / Reclaim观察，等待攻击者Pivot被反向破坏或推进确认。

穿越后连续实体留在外侧

更接近Acceptance。此时原EQH/EQL可能从“潜在扫流动性位置”转换为Break-Retest基准。

回踩

第一次回踩能否守住，决定突破路径是否继续有效。

程序识别要解决什么

问题建议
“相等”允许多大误差？用ATR、点值或最小价格距离定义容差，不用固定像素。
需要几个触点？至少两个有效摆点；更多触点提高可见性，但不能无限重复计数。
哪些摆点有效？必须先有最小摆动/间隔标准，避免每根小波动都变成EQH/EQL。
穿越后何时失效？记录Swept / Accepted / Reclaimed状态，不能永远保留“未触达”标签。
内部/外部流动性Acceptance vs Rejection做专题题库
EQH/EQL用于位置识别，不等同于交易信号。
