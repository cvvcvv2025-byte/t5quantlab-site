FAILED BREAK · RECLAIM · VALUE · TAKEOVER

突破发生过，不代表新价格被市场接受。

Failed Auction关注的是：价格尝试在边界外建立交易，但无法持续，随后重新回到原价值区或原结构内部。失败本身只是Reaction，真正执行仍要等反向接管。

1. Attempt

价格越过前高/前低、区间边界、颈线或流动性区域。

2. No Acceptance

外侧停留不足、跟随不足，或很快回到原区域。

3. Reclaim

重新站回关键位内侧，旧突破路径降级或失效。

4. Takeover

反向破坏Attack Pivot、出现推进或Retest，才进入正式执行层。

FALSE BREAK

只有刺破+收回

可以叫突破失败事件，但证据仍较弱；不能看到长影线就自动反向。

FAILED AUCTION + TAKEOVER

收回后反向获得结果

Reclaim之后进一步破坏原攻击者Pivot，并形成推进/接受，执行证据更完整。

和Volume Profile怎么连接

如果突破后新的成交量/价值没有在外侧建立，价格又重新回到旧HVN/Value区域，可作为“外侧没有持续接受”的辅助证据。但Profile窗口必须固定，不能事后换窗口证明观点。
