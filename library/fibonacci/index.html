Fib 回调与扩展怎么用

Fib 最难的不是记住 0.618，而是先选对推动段。波段选错，后面所有“精准比例”都只是精确地测量了错误对象。

预计阅读 11–14 分钟
核心结论Fib 是测量工具，不是方向工具；方向先由结构和背景决定。
关键问题先找真正改变结构的有效推动，再判断回调深度，而不是随手拉最大高低点。
最有价值Fib 与结构、FVG、OB、流动性、Volume Profile 重叠时，位置意义明显提升。

一、先解决最重要的问题：到底从哪里拉到哪里

多头推动通常从有效低点拉到有效高点，空头推动反过来。但“有效”不是视觉上离得最远，而是这段推动真正产生了市场后果：例如拿下前高、形成 BOS、完成 Sweep 后的接管，或从关键 AOI 强力 displacement。

如果你把整个 H4 大波段拿来指导 M5 入场，回调区会宽得几乎没有执行意义；反过来，如果用 M1 的几根小 K 线去判断 H1 方向，也会过度敏感。Fib 必须和你的决策周期匹配。

图 1：主趋势 Fib 与执行波段 Fib 是两种用途高周期定位置，小周期定进入
高周期 Fib 用来判断整体回调处于浅、中、深哪个区域；执行级 Fib 用来精细化最新攻击段的回踩位置。

二、0.382、0.5、0.618、0.705、0.786 应该怎么看

这些数字不是魔法价格，只是把一段推动切成不同深度。强趋势里，价格可能只回到 0.382 就继续；正常回调经常围绕 0.5–0.618 重新平衡；0.705–0.786 属于较深回调，价格虽然“更便宜”，但原趋势被破坏的风险也更高。

回调区常见含义不能忽略的风险
0.382强趋势浅回调容易追得太急，止损空间可能不够
0.5中间平衡参考不是正式 Fibonacci 比例，也不是天然反转点
0.618常用深度参考单独使用仍然没有方向优势
0.705–0.786深回调 / OTE 类区域可能已经接近结构失效，而不是“更划算”

三、Fib 真正有用的是“重叠”

如果 0.618–0.705 区域刚好落在旧结构、FVG、OB、前低流动性或 Volume Profile 节点附近，它就从一个纯数学比例，变成了多个独立信息重叠的位置。

反过来，如果某个 0.618 落在趋势中部，没有结构、没有流动性、没有反应，它没有必要因为“黄金分割”三个字就被赋予特殊意义。

图 2：高质量 Fib 区不是一条线，而是一片重叠区域0.618–0.705 + FVG + 旧结构
“比例”只是坐标。真正提高质量的是它与市场结构信息发生重叠。

四、从低往高还是从高往低拉

如果你测量的是一段多头推动，从推动起点低点拉到终点高点；空头推动则从高点拉到低点。这个动作本身只是为了让回调比例按正确方向展开。

真正需要避免的是：行情一变动就不停重画 Fib，直到某个比例刚好贴合你的持仓。Fib 应该从已经定义好的有效推动出发，而不是围绕仓位寻找理由。

五、1.272 与 1.618 扩展应该怎么用

扩展比例可以帮助衡量突破原高低点后的潜在距离，但不能当作“价格必须到达”的止盈承诺。更合理的是把 1.272/1.618 与前高低、外部流动性、HVN/LVN、日内高低点等一起比较。

如果 1.618 前面就有明显外部流动性或高周期阻力，死等扩展值会让利润大幅回吐；如果前方空间干净，扩展值则可以作为 Runner 的参考。

图 3：扩展目标必须服从市场障碍结构目标优先于漂亮比例
扩展值最适合做“距离测量”和 Runner 参考，不适合凌驾于真实结构与流动性之上。

六、深回调不是自动更优

很多人喜欢把 0.705/0.786 视为“最佳买入价”，但价格能回这么深，本身也意味着原推动已经被大幅侵蚀。如果同时跌破了关键 HL、形成实体接受，原多头假设可能已经失效。

因此深回调必须配合失效位。不能一边说“0.786 是好价”，一边允许价格无限继续走坏。

危险逻辑：“越跌越接近 0.786，所以越应该加仓。”正确问题应该是：价格越深，原推动结构还成立吗？

七、实战使用顺序

  • 先用 H1/H4 判断背景，不让 Fib 替你决定方向。
  • 找出真正造成结构变化的有效推动段。
  • 按多头低→高、空头高→低绘制。
  • 观察 0.382 / 0.5 / 0.618 / 0.705 / 0.786 所处位置是否与其他 AOI 重叠。
  • 价格进入区域后，等待裸K、Sweep/Reclaim、Micro Break、Retest Hold 等执行证据。
  • 目标用前高低和外部流动性优先，再用 1.272 / 1.618 辅助衡量空间。
  • 关键结构失效时撤销 Fib 假设，不继续靠更深比例扛单。
Fib 最好的用途不是预测市场，而是把“回得浅、回得中、回得深、扩得多远”变成统一尺度。
