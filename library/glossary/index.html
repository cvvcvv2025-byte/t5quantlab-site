STRUCTURE · LIQUIDITY · EXECUTION · RISK · EA

术语表：先统一工作定义，再讨论策略。

同一个词在不同交易流派里可能含义不同。这里采用T5研究中的工作定义，重点是能否被观察、记录和编程。

结构与流动性

BOS

Break of Structure。价格突破当前结构中有意义的摆点；是否有效取决于摆点定义、收盘/影线和后续接受。

CHOCH / MSS

原有推动结构第一次出现反向破坏。它是变化证据，不自动等于完整趋势反转。

Internal Liquidity

位于当前主要波段/区间内部的小高低、局部等高等低和回撤极值，更多描述中间路径。

External Liquidity

位于主要波段或区间外侧的显著前高前低等区域，更常作为结构边界或扩张目标。

EQH / EQL

Equal Highs / Equal Lows。相近高点或低点形成可见订单聚集区域，不要求价格完全相同。

Sweep

价格短暂越过关键流动性。Sweep本身不等于反转，后面是否Reclaim或形成Acceptance更重要。

Reclaim

价格越过关键位后重新回到原区域内侧，表示外侧价格暂时没有被稳定接受。

Acceptance

价格突破后继续在关键位外侧成交并保持，说明市场对新价格区域形成接受。

Rejection

价格到达某区域后快速离开。影线只是表现之一，真正重要的是后续是否形成持续反向推动。

Attack Episode

T5用于审计一段连续攻击的状态单位。用于判断不同信号是否其实属于同一次结构推动。

Attack Pivot

某次Attack最后一个真正支持后续推动的关键结构摆点；被反向破坏可作为接管证据之一。

位置与价格行为

FVG

Fair Value Gap。不平衡/位移留下的价格区间。价值来自上下文、位移和后续反应，不是所有FVG都必须回补。

Order Block

SMC语境中的候选订单区。T5更强调关键位置、真实位移结果和后续是否被尊重。

Premium / Discount

用冻结波段中点划分相对上半/下半区。它是位置过滤，不是Entry。

OTE

Optimal Trade Entry。常见于较深Fib回调区的交易概念；T5不把某个比例视为自动Entry。

Displacement

有方向性的有效位移。重点是是否推进结构和产生跟随，而不是单看一根大K。

Progress Candle

T5用于描述有效推进的工作术语。关注Location、实体、Follow-through和失效，而不是K线长度本身。

Pinbar

长影线拒绝形态。位置和后续确认通常比形态本身更重要。

Engulfing

吞没。不同定义可能看实体或整根K线；程序化前必须先冻结具体口径。

Break & Retest

关键位突破形成接受后，等待第一次回踩守住，再顺突破方向执行。

Second Rejection

第一次Reaction后再次测试关键位置并再次失败，再结合Micro Break/Takeover寻找执行。

Range Boundary

区间上/下边界。中部默认噪声更高；边界要区分拒绝、假突破和外侧接受。

成交量与Market Profile

POC

Point of Control。选定Profile中成交量最大的价格区域/价位，用于描述价值集中位置。

HVN

High Volume Node。高成交量节点，通常表示该区域历史接受度较高。

LVN

Low Volume Node。低成交量节点，常见于历史上快速通过的区域；未来仍可能重新建立平衡。

Value Migration

POC/高成交量价值区域随时间向上或向下迁移，用于辅助判断市场是否在新价格区域建立接受。

Tick Volume

报价变化次数，不等于集中市场真实成交量。CFD/外汇与期货成交量含义不同。

风险与统计

R

以初始风险为单位的收益/亏损表示。例如+2R表示盈利约为初始风险的2倍。

PF

Profit Factor，毛盈利/毛亏损绝对值。单独不能说明回撤、样本质量或稳定性。

Expectancy

单笔期望值。通常结合胜率、平均盈利和平均亏损计算。

MFE

Maximum Favorable Excursion。持仓期间最大有利浮动，用于评估目标和保护是否过早。

MAE

Maximum Adverse Excursion。持仓期间最大不利浮动，用于评估Entry质量和SL位置。

Breakeven / BE

保本。通常指把剩余仓位SL移到成本附近；实际成交仍可能因spread/slippage产生小盈亏。

Partial Close

部分平仓。程序必须确认真实成交量，而不能只记录“已发送请求”。

Runner

第一目标兑现后保留的剩余仓位，用于捕捉更大推动，需要独立管理状态。

No-Widen-Stop

风险单向收紧不变量：保护后不得把SL重新放宽回更差位置。

EA / 程序研究

Repainting

重绘。历史上已经完成的信号随后被修改或消失；要区分未收盘实时更新与已完成历史重写。

Lookahead / Future Leak

策略使用当时尚不可见的数据，导致历史结果虚假改善。

State Machine

把观察、授权、成交、管理和退出阶段显式保存，防止每个tick重新从零判断。

Parity

不同平台/版本之间的语义一致性。目标不是K线完全相同，而是冻结规则在可解释差异下保持一致。

Idempotency

同一个事件重复处理多次，最终结果仍只发生一次。支付回调、订单授权和状态更新都需要。

Audit Trail

保存版本、时间、状态、订单、错误码和结果，使历史行为可以复现。
