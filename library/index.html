STRUCTURE

BOS 与 CHOCH 怎么区分

趋势延续、结构转变和微结构突破，不再混成一个“破位”。

LIQUIDITY

Sweep、Reclaim 与接管

扫流动性只是事件，真正执行还要看价格是否重新收回并改变控制结构。

IMBALANCE

FVG 不等于必回补

FVG 的位置、方向、背景和失效，比“看到缺口就等回补”更重要。

SMC

Order Block 怎么筛掉垃圾区

OB 必须和推动、结构、流动性位置结合，否则图上永远有无数个候选区。

FIB

Fib 回调与扩展怎么用

0.382、0.5、0.618、0.705、0.786 不是魔法数字，关键是波段选择和位置重叠。

VOLUME PROFILE

POC / HVN / LVN 实战理解

高成交量节点和低成交量节点分别代表什么，为什么价格会在“凹进去”的地方停留。

PRICE ACTION

Pinbar 什么时候有效

趋势推进、箱体边界和箱体中部的 Pinbar，含义完全不同。

PATTERN

楔形与三浪推动

形态不是画出来就成立，要看推动次数、压缩、失败延续和结构接管。

EXECUTION

Break & Retest 不是等一次回踩

区分突破接受、假突破、深度收回和第一次有效回踩。
