从“看懂行情”到“写成规则”，每一层只解决一个问题。

Library不追求堆术语。内容按背景、位置、反应、执行、风险和审计组织；每篇尽量说明定义、有效条件、失效和程序字段。

推荐学习顺序

先建立共同框架，再增加高级位置工具。顺序比术语数量重要。

1. Context

多周期、趋势/区间、BOS/CHOCH、颈线。先回答市场处于什么环境。

2. Location

内部/外部流动性、EQH/EQL、FVG、OB、Fib、Premium/Discount、Profile。回答哪里值得观察。

3. Reaction & Execution

Sweep/Reclaim、Acceptance、Break-Retest、二次拒绝、Attack Pivot与推进K。回答什么时候真正行动。

4. Risk & Audit

SL、T1、保本、Runner、MFE/MAE、状态机和CSV。回答规则如何落到账户并被验证。

核心链路

如果只想建立一套不混乱的执行语言，先读这一组。

FRAMEWORK

多周期：Context → Execution

H1/H4背景、M15方向、M5/M1执行，每个周期只回答一个问题。

CoreSTRUCTURE

BOS 与 CHOCH

有效摆点、内部/外部结构与多周期冲突。

STRUCTURE

颈线与结构接管

头肩结构、Break/Reclaim和失效边界。

REACTION

Sweep / Reclaim

扫流动性不是Entry；收回后仍要确认接管。

REACTION

Acceptance vs Rejection

判断突破后市场是否真的愿意留在外侧。

EXECUTION

Break & Retest

Break、外侧接受、第一次Retest与失败切换。

EXECUTION

二次拒绝

第一次Reaction后再次测试失败，再等结构确认。

RISK

风险与持仓管理

SL、T1减仓、保本推进、Runner与账户动作。

CoreREVIEW

MFE / MAE复盘

用最大有利/不利波动检查Entry、SL和保护速度。

高级位置与执行模块

这些内容不是独立交易系统，而是给核心链路增加位置与执行精度。

LIQUIDITY

内部 / 外部流动性

内部更像路径，外部更像边界与目标；所有标签必须带周期。

NewLIQUIDITY

EQH / EQL

等高等低用区域和容差识别，再区分Sweep与Acceptance。

NewLOCATION

Premium / Discount

波段上半/下半只是位置过滤，最重要的是冻结波段。

NewTAKEOVER

Attack Pivot

原攻击者最后一个有效结构Pivot被反向破坏，才更接近趋势接管。

NewPRICE ACTION

推进K / 推进效率

位置、实体、跟随和失效共同决定推进质量，不看单根K大小。

NewRANGE

区间边界交易

中部默认噪声，边界区分Rejection、假突破与外侧接受。

NewVOLUME

Volume Profile × 结构

用POC/HVN/LVN解释接受和价值迁移，而不是生成多空信号。

NewFVG

不平衡与回踩

位移、首次回踩与失效。

SMC

Order Block

位置、位移、结果与失效标准。

FIB

回调与扩展

波段选择、位置和结构目标。

VOLUME

POC / HVN / LVN基础

先理解轮廓，再进入结构结合。

PRICE ACTION

Pinbar

拒绝痕迹必须结合位置和后续确认。

PATTERN

楔形与三次推动

推动效率、衰竭和失败延续。
