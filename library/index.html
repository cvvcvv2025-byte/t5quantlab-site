STRUCTURE · LIQUIDITY · EXECUTION · RISK · DATA · CODE

Library 不是术语字典，而是一套从“看懂行情”到“写成规则”的学习地图。

每篇内容尽量回答四件事：定义是什么、什么时候有效、什么时候失效、如何变成可复盘/可编程规则。

推荐学习路线

先建立背景与结构，再学位置和执行，最后进入风险、验证与自动化。

1. 背景与结构

先读多周期框架、BOS/CHOCH和裸K阅读，不急着找Entry。

2. 位置

流动性、FVG、OB、Fib、Volume Profile用于回答“哪里值得观察”。

3. 执行

Sweep/Reclaim、Break-Retest、二次拒绝、Pinbar和Micro Break用于回答“什么时候真的行动”。

4. 风险与验证

把SL、T1、保本、Runner、审计字段写清楚，再进入EA和源码实现。
