Indicators / Failure Regimes
REGIME FIRST · FAILURE MODES · NO UNIVERSAL INDICATOR

指标不是“准不准”，而是当前环境是否适合它。

很多指标策略失败，不是公式失效，而是把趋势工具用在震荡、把均值回归工具用在单边、把低波动参数直接带进事件行情。先识别Regime，再决定是否允许信号生效。

五类常见环境

TREND方向持续、回撤浅、动量工具可能长期保持极值。
RANGE边界有效、中部噪声、趋势交叉频繁Whipsaw。
COMPRESSION波动收缩，很多方向信号缺乏延续。
EXPANSION波动突然放大，固定止损与均值假设容易失效。
EVENT / THIN新闻、开盘、低流动性时滑点和异常K线会破坏历史假设。

趋势环境：哪些规则最容易出错

RSI / STOCHASTIC

极值钝化

强趋势中RSI可以长期高于70，Stochastic也可以长时间停留在高位。极值首先表示动量强，而不是自动反转。

BOLLINGER

Walk the Band

价格沿上轨运行时，“碰上轨做空”的均值回归模型会连续受伤。BandWidth扩张反而可能说明趋势正在延续。

DIVERGENCE

背离持续

动量峰值下降并不阻止价格继续创新高。背离更适合做警报，不应该单独承担Entry。

震荡环境：趋势指标为什么反复打脸

MA CROSS

交叉过密

快慢均线在窄幅区间里不断交换位置，信号数量增加，但真正位移不足。

MACD

零轴噪声

MACD围绕零轴反复穿越时，趋势/动量优势很弱。需要Regime过滤，而不是更频繁地反手。

SUPERTREND / PSAR

翻向频繁

趋势跟踪工具在箱体中会连续翻向。解决问题的方向通常是环境过滤，不是无限调参数。

压缩、扩张与事件行情

COMPRESSION

压缩期假突破

低ATR、低BandWidth环境里，方向指标可能看似产生信号，但没有足够波动兑现目标。

EXPANSION

固定止损失真

ATR突然放大时，固定5美元/10点的止损不再代表同样的市场风险。

EVENT

历史执行假设破坏

新闻或流动性稀薄时，滑点、跳空和Spread扩张可能让“图上完美”的策略变成不同策略。

把Regime写成程序，而不是感觉

trend_regime = ADX(14) > threshold AND EMA20_slope > 0 range_regime = ADX(14) < threshold AND bandwidth < percentile compression = ATR(14) / price < rolling_percentile expansion = ATR(14) / price > rolling_percentile allow_mean_reversion = range_regime AND NOT expansion allow_trend_following = trend_regime AND NOT event_block

这些只是结构示例。真正要验证的是阈值是否跨时期稳定、不同品种是否需要归一化，以及加入Regime后是否真的改善期望值而不是只减少亏损样本。
