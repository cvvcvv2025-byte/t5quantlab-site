INDICATOR TRADING · NOT SMC-ONLY

指标不是答案，它是对价格某个维度的压缩。

MACD、RSI、布林带、均线、ADX、Ichimoku都可以形成完整交易体系。T5不要求用户改学SMC，而是要求先搞清：指标在测什么、在哪类环境有效、什么时候会失真、如何把规则写清楚并验证。

选择指标先看策略类型找对应书籍

先问这5个问题

MEASURE它测趋势、动量、波动率、成交量，还是相对位置？
REGIME趋势、区间、压缩、扩张，哪种环境更匹配？
TRIGGER交叉、突破、背离、回归、斜率还是位置？
INVALID什么出现后说明这次读法失效？
TEST规则能否写成可重复、可回测、可审计的句子？

按指标家族选择

不要把所有指标放在一个图上“投票”。先区分它们各自在测什么，避免重复计算同一件事。

TREND

Moving Averages

SMA / EMA、斜率、排列、回踩与趋势过滤。

适合：趋势过滤、动态参考
TREND + MOMENTUM

MACD

零轴、快慢线、Histogram、背离与多周期冲突。

误区：金叉≠自动买点
MOMENTUM

RSI

超买超卖、Range Shift、背离与趋势中的高位钝化。

误区：70以上≠应该做空
MOMENTUM / RANGE

Stochastic

%K/%D、区间节奏、钝化和趋势过滤。

适合：均值回归、区间节奏
VOLATILITY + LOCATION

Bollinger Bands

Band Width、Squeeze、Walk the Band、均值回归与扩张。

误区：碰上轨≠直接空
TREND STRENGTH

ADX / DMI

趋势强度与方向分开读，避免把高ADX直接等同做多。

适合：Regime过滤
FULL FRAMEWORK

Ichimoku

Tenkan、Kijun、Cloud、Chikou与多维趋势结构。

适合：独立体系而非单点信号
VOLATILITY / BREAKOUT

ATR / Keltner / Donchian

真实波幅、波动归一化、通道突破与趋势跟随。

适合：SL距离、Breakout
VOLUME / PARTICIPATION

VWAP / OBV / MFI

均价、累积量能、量价关系与参与度。

注意：不同市场成交量质量不同

指标组合不是“越多越安全”

EMA、MACD、RSI都由价格派生。三个一起同向，不代表获得了三份独立证据。

BAD COMBO

EMA + MACD + RSI 同向投票

很可能只是同一段价格趋势被三种公式重复表达。看起来“共振”，实际信息增量有限。

BETTER

趋势 + 波动率 + 位置

例如EMA定义方向、ATR/Bollinger定义环境、结构或VWAP定义位置，信息维度更独立。

BEST PRACTICE

先定义主指标和辅助指标

谁负责方向？谁负责过滤？谁负责Trigger？任何指标都不能同时承担所有职责。

从指标变成可验证策略

写清输入：周期、参数、价格源、是否使用收盘确认。
写清Regime：趋势/区间/高波动/低波动分别允许什么。
写清Signal：交叉、斜率、Band突破、背离必须有程序定义。
写清Entry：信号出现即进、下一根开盘、回踩、还是额外过滤。
写清Invalidation：止损和“信号失效”不能混为一谈。
记录MFE/MAE、滑点、延迟和未成交，避免只看净利润。
