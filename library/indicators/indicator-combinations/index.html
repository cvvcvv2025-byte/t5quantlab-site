指标组合不是投票，先给每个指标分配职责。

EMA、MACD、RSI、Stochastic都来自价格。多个指标同时“同向”不等于多份独立证据。更合理的方法是先按信息维度分工：趋势、动量、波动率、位置、参与度和风险。

六种更合理的组合方式

不是推荐交易信号，而是展示不同信息维度如何分工。

TREND + MOMENTUM

EMA + MACD

EMA负责趋势背景，MACD负责回撤后动量重新扩张。不要再让两者同时决定“方向”和“入场”。

VOLATILITY + MOMENTUM

Bollinger + RSI

布林带负责相对位置和波动环境，RSI负责动量极值。强趋势Walk the Band时必须禁止机械逆势。

REGIME + DIRECTION

ADX + MACD

ADX只判断趋势强度，不判断方向；MACD提供方向和动量。职责天然互补。

LOCATION + MOMENTUM

VWAP + RSI

VWAP提供相对均价位置，RSI观察短期动量偏离。适合研究均值回归，但需要明确Session和趋势过滤。

BREAKOUT + VOLATILITY

Donchian + ATR

Donchian负责突破，ATR负责风险归一化与低波动过滤。不要把ATR方向化。

FULL FRAMEWORK

Ichimoku + ATR

Ichimoku已经包含较多趋势与位置维度，额外加入ATR更适合承担风险，而不是再叠一堆趋势指标。

最常见的“伪共振”

REDUNDANCY

EMA + MACD + RSI + Stochastic

看似四重确认，很多时候只是同一段价格上涨被四种公式重复表达。真实独立信息没有想象中多。

VOTE SYSTEM

3个指标同意就下单

如果没有定义每个指标为何存在，投票系统很难解释失效环境，也很难审计参数。

PARAMETER TUNING

不断调到历史最好

组合越复杂，自由度越高，越容易过拟合。任何新增指标都应证明它提供了新增信息，而不是美化历史曲线。

组合策略冻结模板

REGIME = ADX(14) > threshold DIRECTION = EMA20 > EMA50 LOCATION = price pulls back toward EMA20 / VWAP TRIGGER = MACD histogram re-expands AND close confirms INVALIDATION = price invalidates structure, NOT simply MACD crosses back RISK = fixed account risk / ATR-normalized stop AUDIT = MFE + MAE + slippage + regime label

关键不是这组条件本身，而是每个字段都只有一个明确职责。这样才能做独立消融测试：删除某一项后，期望值、交易频率、回撤是否真的改善。
