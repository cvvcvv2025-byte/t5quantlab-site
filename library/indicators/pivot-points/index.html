Indicators / Pivot Points
PIVOT · R1/R2 · S1/S2 · SESSION

Pivot Points给的是预先计算的参考价，不是自动支撑阻力。

Classic、Fibonacci、Camarilla等Pivot都根据前一周期的高低收计算下一周期参考层级。它的价值在于“开盘前就已知”，但是否有效仍取决于市场是否在这些区域产生真实反应。

先确认四件事

FORMULAClassic / Fibonacci / Camarilla不能混用后再挑最好看的线。
SESSION前一日高低收的切分时间会直接改变Pivot。
REACTION价格触及R1/S1只是Location，不代表必须反转。
CONFLUENCE与VWAP、结构、前高低等重叠时可作为额外位置证据。

Classic Pivot基础

P = (High_prev + Low_prev + Close_prev) / 3 R1 = 2 × P - Low_prev S1 = 2 × P - High_prev R2 = P + (High_prev - Low_prev) S2 = P - (High_prev - Low_prev)

公式简单不代表交易逻辑简单。关键是上一交易日如何定义、周末/节假日如何处理、经纪商服务器日线是否与目标市场一致。

REVERSAL

触及后拒绝

R/S层级提供Location，真正反转仍需要拒绝、失败接受或其他Trigger。

BREAKOUT

突破后接受

实体收盘越过R1/S1并持续接受时，原本的“反转位”可能转成突破路径。

SESSION

时区不一致

TradingView、MT5和不同Broker的日线切分可能不同，Pivot层级因此会偏移。

EA规则化

pivot = (prev_session_high + prev_session_low + prev_session_close) / 3 at_R1 = abs(close - R1) < tolerance * ATR reversal_entry = at_R1 AND rejection_trigger breakout_entry = close > R1 AND acceptance_rule

程序里必须冻结Session边界和DST处理。否则同一策略跨Broker时，Pivot本身就不是同一组价位。
