SUPERTREND · PARABOLIC SAR · TRAILING LOGIC

趋势跟踪工具最擅长“跟”，不擅长提前猜拐点。

Supertrend通常把ATR与价格基准结合成方向/跟踪线；Parabolic SAR用加速因子让止损点逐渐靠近价格。两者共同弱点都是震荡期频繁翻向。

职责

SUPERTREND趋势方向、ATR缓冲、翻向规则。
PSAR趋势跟踪与加速移动止损。
BEST REGIME方向性持续、波动展开的趋势环境。
WEAK REGIME横盘、噪声、频繁假突破。

常见错误

FLIP

颜色翻转就反手

如果没有Regime过滤，横盘期会连续多空翻转，交易成本可能吞掉理论优势。

TRAILING

把跟踪线当结构失效

Supertrend/PSAR是公式化移动线，不等同于价格结构真正失效位。

PARAMETER

只优化ATR倍数

越贴近价格越敏感，越远越迟钝；最佳参数很容易只是在拟合历史噪声。

适合怎样组合

Supertrend + ADXADX负责趋势强度Regime，Supertrend负责方向/跟踪。
PSAR + Moving Average均线先过滤大方向，PSAR只用于同向跟踪和退出。
Supertrend + Price Structure结构负责失效，Supertrend负责机械跟踪，避免混淆职责。

EA规则化

allow_long = regime == TREND AND supertrend_direction == UP entry = allow_long AND primary_trigger trail = max(previous_stop, supertrend_line) exit_psar = psar_flip AND close_confirmed

如果一根K线内既触发翻向又触发止损，EA必须定义事件优先级和成交价格，不然回测与实盘会产生差异。
