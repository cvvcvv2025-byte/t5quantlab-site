INTERNAL · EXTERNAL · PATH · TARGET · INVALIDATION

内部流动性更像“路径”，外部流动性更像“边界与目标”。

两者都不是自动买卖信号。真正有用的是：它们告诉你价格在当前位置附近可能先处理什么、最终又可能去测试什么，并帮助定义结构是否已经完成。

图解｜同一波段内的内部与外部流动性先冻结主要波段，再判断高低点属于路径还是边界。
内部流动性描述主要波段内部的中间路径；外部流动性位于主要结构外侧。价格是否真的去处理某个目标，仍要由当下推进、Acceptance/Rejection和Attack决定。
INTERNAL LIQUIDITY

内部流动性

位于当前主要波段或区间内部的小高低点、局部等高/等低、短期回撤极值。它们更适合描述价格在到达主要边界前的中间路径。

EXTERNAL LIQUIDITY

外部流动性

位于主要波段、区间或有效结构外侧的前高前低、显著等高等低等位置。它们更常作为结构扩张目标或关键失效边界。

最常见的三个错误

01

把所有小高低都叫外部流动性

这样会失去层级。先冻结“当前主要波段/区间”，再判断某个高低点是在内部还是外侧。

02

看到流动性就预测一定会被扫

流动性是位置，不是保证。价格可以在到达之前完成反向接受，也可以穿过后继续扩张。

03

内部目标没处理完就假设直接去外部

路径分析需要结合推进效率、接受/拒绝和当前Attack，而不是机械按顺序“打点”。

如何放进多周期框架

周期职责主要看什么用途
H1/H4主要波段外部流动性、区间边界背景与大目标
M15内部流动性、局部结构接受判断Attack是否仍在延续
M5/M1短期扫流动性、Reclaim、Micro Break执行与失效
同一个价位可以在一个周期属于“外部”，在更高周期却只是“内部”。因此所有流动性标签都必须带周期和结构上下文。

转成可编程规则时至少记录

  • LiquidityType：Internal / External
  • Timeframe：该层级来自哪个周期
  • ReferenceSwing：归属哪个波段/区间
  • Status：Untouched / Swept / Accepted / Reclaimed
  • DistanceToEntry：距离当前执行位多远
  • Role：Path / Target / Invalidation
