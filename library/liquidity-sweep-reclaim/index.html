Sweep、Reclaim 与接管

扫流动性只说明一侧订单被触发。真正决定能不能交易的，是扫完之后价格如何处理这片区域：收回、接管，还是在外侧形成接受。

预计阅读 12–15 分钟
核心结论Sweep 是事件，不是方向；Reclaim 是否定外侧接受；Takeover 才开始证明控制权变化。
两条路径Sweep-Reversal 与 Break-Acceptance-Retest 必须同时保留，不能预设每次清扫都反转。
执行重点最危险的是在 Sweep 当根追反转；更稳的是等待 Micro Break 或第一次 Retest Hold。

一、先理解“流动性”到底在说什么

前高、前低、等高、等低、显眼的区间边界，往往聚集止损、突破单和挂单。价格到达这些位置时，交易活动会明显增加，所以它们常被统称为流动性位置。

但“这里有流动性”并不等于“价格到这里一定反转”。同一片流动性既可能成为反转燃料，也可能成为突破后的加速燃料。方向必须看清扫之后的接受状态。

图 1：同一片流动性，存在两种完全不同的后续扫完后关键不是影线，而是“收回”还是“接受”
同样是刺破前高，一条路径迅速收回，另一条路径站稳外侧。只凭“扫了”去逆势，会把两个完全不同的市场状态混为一谈。

二、Sweep：订单被触发，不代表方向已经反转

Sweep 常见表现是价格快速刺破显眼高低点，然后留下影线或短暂收回。它能告诉你的只有：这片位置真的有交易活动，原先停留在这里的订单被触发了。

它不能单独回答：是谁吸收了这些订单、谁在主动推进、外侧价格是否被市场接受。因此，Sweep 当根直接反向入场，是最容易被二次突破打掉的做法之一。

最常见错误：“长上影扫前高 = 必空”“长下影扫前低 = 必多”。如果后续实体重新站回外侧并持续成交，这根影线反而只是突破过程的一部分。

三、Reclaim：价格重新收回关键区域

Reclaim 比 Sweep 更重要，因为它开始否定外侧突破。我们关注的不是价格“碰回来”，而是实体重新回到关键区域内，并且后续 K 线没有立刻再次丢失。

一个更有质量的 Reclaim 通常具备：收回速度快、实体明确、后续跟随，且攻击方向不能快速夺回外侧。反之，如果价格反复在边界内外穿越，说明市场还没有明确拒绝哪一侧。

更像有效 Reclaim

扫出后快速实体收回，下一段反向推进有连续性，外侧没有形成新的稳定成交区。

更像普通回抽

只是一根影线回到区域内，随后立刻重新站回外侧，或者在边界附近反复横穿。

四、Takeover：攻击方的微结构被真正打坏

Reclaim 只是说明“原突破没有被顺利接受”，但还没有证明另一方已经接管。真正值得升级信号等级的是：反向推进开始打破攻击方最近承担结构意义的 pivot。

例如价格向上扫前高后收回，如果空头推进进一步跌破刚才上攻过程里的最后一个有效 higher low / attacker pivot，才开始出现 Takeover 证据。

图 2：Sweep → Reclaim → Micro Break → Retest Hold从事件到可执行证据，是一条链，不是一根 K 线
Micro Break 是“控制权开始变化”的证据，第一次 Retest Hold 则是在验证这次变化能不能维持。

五、为什么第一次 Retest Hold 很关键

很多人等到 Micro Break 后才开始追单，结果刚好追在反向推进末端。第一次回踩的价值在于：它把“刚才那段推进”从一次性冲动，变成可以验证的新结构。

如果回踩重新跌回/涨回原攻击结构内部，Takeover 质量就下降；如果回踩守住新结构并再次推进，Main Entry 的依据会比 Sweep 当根清楚得多。

六、另一条必须保留的路径：Break-Acceptance-Retest

不是每次扫流动性都应该寻找反转。如果价格突破流动性后，实体持续留在外侧，回踩原边界时又能守住，这更像“突破被接受”。此时还坚持做反转，本质上是在和已经发生的市场状态对抗。

图 3：突破接受与假突破的分界站稳外侧 + 回踩守住，和深度收回，是两套不同路径
真正要做的不是“猜主力”，而是判断市场有没有接受新的价格区域。

七、把它变成可执行流程

  • 先标出前高、前低、等高等低和真正重要的外部流动性。
  • 等待 Sweep，先不下结论。
  • 观察是快速 Reclaim，还是实体持续留在外侧。
  • 若 Reclaim，继续等 Micro Break / attacker pivot 失效。
  • 优先观察第一次 Retest Hold，而不是追在推进末端。
  • 若外侧接受成立，切换 Break-Acceptance-Retest，不死守反转假设。

八、什么时候原假设应该失效

反转路径里，如果价格重新站回被扫流动性外侧，并持续形成实体接受，反转假设就应该被撤销。延续路径里，如果价格深度收回边界并打坏刚形成的接受结构，突破假设也必须撤销。

真正成熟的模型不是“永远看多/看空”，而是每一步都有明确的失效条件。方向不是信仰，状态可以切换。

阶段你真正得到的信息更合理的动作
Sweep一侧流动性被触发观察，不抢跑
Reclaim外侧突破暂未被接受进入反转观察
Micro Break攻击方短期结构失效Probe / Wait
Retest Hold新结构第一次验证成功Main Entry 候选
