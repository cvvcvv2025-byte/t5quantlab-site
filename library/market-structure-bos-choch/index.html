STRUCTURE NOTE 001

BOS 与 CHOCH 怎么区分

最常见的问题不是“看不懂结构”，而是把所有破位都叫 BOS 或 CHOCH。先分层，再命名。

先确定你在看哪个层级

H1 的结构、M15 的结构和 M5 的微结构可以同时出现相反信号。高周期决定背景，中周期决定方向，小周期负责执行。如果不先固定层级，一个 M1 的微突破就可能被误判成 H1 反转。

BOS：原方向继续拿下有效摆点

上升结构里，价格在更高低点之后继续突破前高；下降结构里，在更低高点之后继续跌破前低。重点是“延续原有控制结构”。

CHOCH：第一次破坏原控制结构

CHOCH 更像预警，不等于反转完成。上升趋势里跌破最近有效的更高低点，只能说明原多头结构被破坏；后面还要看价格是否能形成新的更低高点、更低低点，以及回踩是否失败。

结构转变不是一根 K 线，而是一段控制权变化过程。

微结构突破的用途

在 Sweep/Reclaim 之后，小周期打破攻击方最近 pivot，可以作为 Takeover 的早期证据。但它不该直接替代高周期方向。我们更倾向把它用于 Probe / Wait，而不是直接视为 Main Entry。
