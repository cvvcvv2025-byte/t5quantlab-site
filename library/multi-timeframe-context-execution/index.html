T5 Quant Lab / Library / Multi-Timeframe
CONTEXT → DIRECTION → LOCATION → EXECUTION

多周期不是“多看几张图”，而是每个周期只回答一个问题。

高周期决定你在哪里，中周期决定当前哪一侧更占优，低周期只负责回答：现在有没有足够明确的执行触发。

四层职责

如果同一条规则同时在H1、M15、M5重复使用，多周期就会退化成重复确认。

H1 / H4 · CONTEXT

背景

判断主导结构、重要高低点、外部流动性、明显失衡、前高前低和当前是否处于扩张或压缩环境。

M15 · DIRECTION

方向与工作区

确认当前推动方向、最近有效摆点、接受/拒绝、是否接近可执行位置。M15负责把高周期背景缩小成当天的工作区。

M5 · EXECUTION

执行

等待Sweep-Reclaim、Break-Retest、Micro Break、二次拒绝、推进K等可定义事件，而不是看到“像反转”就下单。

M1 · PRECISION

精细化，不负责改变方向

M1可以优化失效位、攻击者Pivot或更早的Micro Break，但不能因为一分钟出现一个Pinbar就推翻H1/M15背景。

一个完整决策链

每一步都可以写成“是/否”，这样才能审计。

1. 高周期：价格现在处于什么环境？

趋势推进、趋势末端、区间内部、区间边界、外部流动性附近，答案不同，低周期同一个形态的意义也不同。

2. M15：当前推动有没有被接管？

先看谁在制造更有效的高低点，再看前一侧推动是否失效。不要把一次影线当成趋势切换。

3. 位置：触发发生在哪里？

同样的Pinbar、吞没、CHOCH，发生在区间中间和外部流动性扫过之后，质量完全不同。

4. M5/M1：执行事件是否闭合？

例如Sweep → Reclaim → Break attacker pivot → First Retest Hold；任何中间步骤没完成，都仍属于观察。

最常见的五个错误

错误为什么危险替代做法
高周期看多，低周期一律只找多忽略高周期内部仍可有完整反向波段把高周期当背景，而不是强制方向
周期越多确认越强常常只是同一价格信息被重复计算每个周期只承担一层职责
M1先动就提前猜方向噪音极大，容易追最差价格M1只优化执行，不决定主背景
看到CHOCH就认为反转完成内部结构变化可能只是回调结合位置、Reclaim和攻击者Pivot
高周期区域画得过宽几乎任何低周期触发都能被解释成“在区域内”把AOI缩小到真正产生位移/接受的位置

可直接复盘的模板

H1/H4：当前结构、外部流动性、关键失效位。
M15：当前推动方向、工作区、是否出现接受/拒绝。
M5：触发模型、Entry、失效位、T1/T2逻辑。
M1：仅记录是否用于精细化，不允许单独改变主判断。
结果：成交/未成交、MFE/MAE、T1/T2、保护动作、是否存在更早或更晚的合理执行。
