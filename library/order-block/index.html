SMC NOTE 004

Order Block 怎么筛掉垃圾区

如果每根反向 K 线都能画成 OB，那么 OB 就没有筛选价值。真正要看的是它是否参与了有效推动和结构变化。

OB 不是“最后一根反向 K 线”的机械定义

一段区域之所以值得关注，不是因为它长得像教科书，而是因为价格从这里离开后产生了有意义的结果，例如快速 displacement、结构突破、流动性获取后反转或关键失衡。

四个筛选条件

第一，看它是否位于重要位置；第二，看离开时有没有明显推动；第三，看推动是否改变或延续了有效结构；第四，看区域是否与 FVG、前高低、Fib 或高周期 AOI 重叠。

第一次回踩通常最值得观察

一个区域被反复测试后，剩余订单和信息优势可能下降。因此第一次高质量回踩通常比第三、第四次反复接触更值得重视，但仍需要执行级确认。

不要把 OB 当成必须反弹的墙

价格如果深度穿透并在另一侧形成接受，原 OB 就应该降级甚至失效。继续不断扩大区域去“解释”价格，只是在事后修图。

好 OB 的核心不是矩形画得准，而是它曾经造成什么。
检查项较强较弱
位置HTF AOI / 流动性附近区间中部
离开快速 displacement缓慢磨出
结果BOS / CHOCH / 明确推进无结构影响
回踩首次、快速拒绝多次反复穿透
