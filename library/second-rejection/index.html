T5 Quant Lab / Library / Second Rejection
FIRST REACTION ≠ ENTRY · SECOND TEST · FAILURE · TAKEOVER

第一次拒绝说明“这里有人反应”，第二次拒绝才开始回答“这次反应能不能接管”。

二次拒绝模型的价值，不是寻找漂亮影线，而是把“位置有效”与“执行有效”分开。

STEP 1

第一次反应

价格到达外部流动性、FVG/OB、前高前低、Fib回调区或成交量结构后出现明显拒绝。此时只记录Reaction，不默认进场。

STEP 2

再次测试

价格回到同一关键区域，测试深度、实体接受和推动效率决定第一次反应是否仍有效。

STEP 3

第二次失败 + 接管

第二次测试再次无法接受在关键位外侧，同时出现微结构破坏、吞没、推进或攻击者Pivot被突破，才进入Execution。

不是“两次碰到”就叫二次拒绝

情形判断原因
第一次长影线，第二次直接实体突破并接受无效第二次测试证明该位置已被接受
两次测试之间没有形成可识别的反向推动偏弱说明第一次反应没有建立任何控制权
第二次测试更浅，随后突破攻击者Pivot更有价值说明测试失败且对手推动效率下降
发生在区间中部通常降级没有明确位置优势，容易变成噪音
发生在外部流动性扫过后并重新收回重点观察位置、流动性与执行事件形成闭环

与 Fibonacci 的关系

Fib不能替代结构，它只帮助描述第二次测试的深度和价格是否仍处于合理回调区。

0.382–0.5

浅回调

常见于强势推动后的第一次或第二次测试。优点是失效位较近，缺点是过早判断容易被更深回调扫掉。

0.618–0.786

深回调

如果结构仍未失效，深回调可能给更好的价格；但若实体持续接受在关键位外侧，不能因为“到了0.705/0.786”就逆势进场。

核心：Fib负责“价格回了多深”，结构负责“控制权有没有变化”，流动性负责“为什么这里值得观察”，执行模型负责“什么时候可以下单”。

执行模板

位置

标记外部流动性/关键摆点/FVG/OB/Fib重叠区，不在区间中间主动找二次拒绝。

Reaction 1

第一次收回、长影、吞没或强反向位移，只记“有反应”。

Test 2

第二次回测观察是否更浅、推动是否减弱、实体是否无法接受。

Execution

突破攻击者Pivot / Micro Break / 明确推进后，再考虑第一次回踩或立即右侧执行。
