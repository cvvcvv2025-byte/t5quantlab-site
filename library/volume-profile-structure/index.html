POC · HVN · LVN · ACCEPTANCE · VALUE MIGRATION

Volume Profile不是另一套“支撑阻力线”，它更适合解释哪里被接受、哪里被快速穿越。

POC/HVN/LVN本身不负责给方向。真正有用的是把成交量分布与当前结构、Break/Reclaim、区间边界和价值迁移放在一起。

POC

成交量最集中价格

代表所选样本内最活跃的价格区域之一，更适合理解价值中心，而不是自动当成反转线。

HVN

高成交量节点

价格常在这里停留、反复交易或形成平衡。进入HVN后，推进速度可能降低。

LVN

低成交量节点

代表历史上较少接受的区域。价格一旦重新进入，可能快速穿越；但也可能在边缘被拒绝。

和结构结合的四种用法

结构事件Profile信息解释
Break后外侧站稳价值/POC开始向突破方向迁移支持Acceptance，而不仅是单次刺破
突破后重新回到原HVN外侧没有形成新价值Break可能失败，重新进入平衡
进入LVN历史接受较少观察是否快速穿越，或在边缘出现强拒绝
区间边界+HVN边缘价值区边缘与结构边界重合更适合等待Reaction，不直接预测方向

为什么“最少成交的地方反而会横盘”并不矛盾

Profile是对选定历史样本的统计。一个位置过去是LVN，不代表未来到达时一定高速穿越。新的买卖双方可以在这里重新建立平衡，使原LVN逐渐变成新的成交密集区。

因此Profile必须带时间窗口。昨日的POC/HVN/LVN、当前Session的Profile和长期Composite Profile回答的是不同问题，不能混在一起。

用于审计的字段

  • ProfileWindow：Session / Swing / Composite
  • POC / VAH / VAL（若使用价值区）
  • NearestHVN / NearestLVN
  • ValueMigrationDirection
  • EntryRelativeToProfile：Inside Value / Edge / Outside
  • StructureEvent：Break / Reclaim / Retest
