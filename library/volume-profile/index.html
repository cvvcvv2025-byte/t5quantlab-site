VOLUME NOTE 006

POC / HVN / LVN 实战理解

成交量分布不是“柱子越长越能涨”。它描述的是不同价格上成交接受程度，以及价格在这些区域之间如何迁移。

POC：样本区间内成交最集中的价格

POC 可以理解为当前统计区间里最被市场接受的价格之一。价格靠近 POC 时经常更容易出现双向交易和停留，但它不是固定支撑或阻力。

HVN：高接受区

HVN 是较厚的成交量区域，通常代表市场曾经在这里花了更多时间和成交。价格重新进入后，常见行为是旋转、震荡或重新寻找价值中心。

LVN：低接受区

LVN 是成交相对稀薄的区域。很多人会误以为“成交少就绝不会横盘”。实际上，价格可以暂时停在 LVN 附近进行新的价格发现；只有后续成交继续累积，它才可能逐渐从旧 LVN 变成新的接受区。

Volume Profile 描述过去哪里被接受，不保证未来哪里一定反转。

为什么凹进去的地方也会横盘

旧的 LVN 只说明历史样本里这里成交少。当前行情到达后，如果买卖双方开始重新博弈，就可能暂时横盘并累积新的成交量。因此要区分“历史轮廓”和“当前实时形成中的分布”。

与结构怎么结合

更实用的方式是把 POC/HVN/LVN 当作 Location 层：先看高周期背景，再看价格是否到达 HVN 边缘、LVN 通道或 POC 附近，最后用裸K、Sweep/Reclaim、Break-Retest 决定执行。

如果没有可靠成交量源，外汇现货平台的 tick volume 与交易所真实成交量需要明确区分。研究期尽量使用来源清楚的数据。
