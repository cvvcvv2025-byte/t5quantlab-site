POC / HVN / LVN 实战理解

Volume Profile 不是“柱子越长越容易涨跌”。它描述的是市场过去在哪些价格接受度高、哪些价格接受度低，以及当前价格正在如何重新发现价值。

预计阅读 12–15 分钟
核心结论POC/HVN/LVN 是 Location 信息，不是独立方向信号。
最关键区分历史轮廓描述过去；当前价格到来后，分布会继续变化，旧 LVN 也可能形成新接受。
执行原则先看背景与结构，再把 Profile 当位置层，最后靠价格反应决定执行。

一、Volume Profile 到底在看什么

普通成交量柱告诉你“某一根 K 线期间成交了多少”，Volume Profile 则把成交量重新按价格横向分布。这样可以看到：哪些价格过去成交得最多、哪些价格成交得少。

它更接近一个“价格接受地图”。市场在某些价格花了很多时间并完成大量交易，说明那里曾经比较容易达成双边成交；另一些价格被快速穿越，说明过去市场对那里接受度较低。

图 1：典型 Volume Profile横柱长度代表该价格附近的成交集中程度
最长横柱通常对应样本区间里的 POC；一大片厚区域更接近 HVN；明显凹陷处更接近 LVN。

二、POC：最多成交，不等于最强支撑阻力

POC 是当前统计区间里成交最集中的价格。它常常代表一个价值中心，价格回到附近时容易出现双向交易、停留或旋转。

但 POC 不是固定支撑或阻力。价格可以围绕它来回穿越，因为“高接受”本身就意味着这里容易成交。真正要看的是价格从哪一侧进入、背景是什么，以及是否在 POC 附近重新建立价值。

常见误区：把 POC 当成一条“碰到就反弹”的水平线。实际上，POC 更像磁场或价值中心，而不是天然的拒绝边界。

三、HVN：高接受区为什么容易震荡

HVN 是成交较厚的区域，往往代表市场曾经在这里做了大量双向交易。价格重新进入后，常见现象不是立刻单边离开，而是重新寻找平衡，出现旋转和震荡。

因此在 HVN 中部追突破通常性价比不高。更值得关注的是 HVN 边缘：价格是在边缘被拒绝，还是接受进入内部。如果被接受进入，往往更容易向下一个价值中心迁移。

四、LVN：低接受区为什么有时又会横盘

LVN 只描述“历史样本里这里成交少”，不代表未来永远成交少。价格第一次回到旧 LVN 时，可能快速穿越，也可能因为新的买卖双方进入，开始在这里重新进行价格发现。

如果当前成交持续累积，一个旧 LVN 完全可能逐渐变成新的接受区。所以你之前看到“明明是凹进去的地方，为什么价格在这里横盘”，答案就在这里：你看到的是旧分布，而市场正在实时创造新分布。

图 2：旧 LVN 可以变成新的接受区历史轮廓不会自动约束未来
旧 LVN 是历史信息。当前市场如果开始在这里大量成交，它的性质会改变。

五、真正有用的是“价值迁移”

与其只盯一个静态 POC，不如观察价值中心如何移动。如果新的 POC/HVN 逐渐向上迁移，说明市场接受价格在抬高；反过来，如果价值持续下移，说明更低价格正在被接受。

这种“接受区域迁移”比单看某一根大阳线/大阴线更稳定，因为它描述的是一段时间内市场真正在哪里完成了成交。

六、怎么和结构、流动性结合

Profile 最适合承担 Location 层。比如 H1 背景偏多，价格回到一个旧 HVN 边缘或 LVN 通道，同时附近还有前低流动性、Fib 0.618、FVG，那么这里是一个值得观察反应的区域。

真正入场仍然交给价格行为：Sweep/Reclaim、Break-Retest、Pinbar、Micro Break、Retest Hold。Volume Profile 不应该自己承担 Entry。

图 3：Profile 是位置层，结构负责执行Context → Location → Reaction → Execution
不要让 Volume Profile 直接从“Location”跳到“Entry”。中间必须经过反应和执行确认。

七、数据源必须说清楚

期货交易所成交量和外汇现货经纪商的 tick volume 不是同一个概念。做 XAUUSD 时，如果你引用的是 COMEX GC 的交易所数据，应明确它是黄金期货成交量，而不是某个经纪商现货黄金的完整全球成交量。

研究时最怕“数据看起来很专业，但来源不清楚”。同一张 Profile 用不同市场、不同会话、不同样本区间，结果都可能不同。

八、实战检查清单

  • 先确认 Profile 的数据源、统计区间和会话范围。
  • 确定 POC/HVN/LVN 是历史位置，不提前假设一定反转。
  • 观察价格是从哪一侧进入该区域，以及高周期结构是否支持当前方向。
  • HVN 中部少追单，更重视边缘接受/拒绝。
  • 旧 LVN 被横盘时，考虑“新接受正在形成”，不要死守旧标签。
  • 最后用结构与裸K完成执行，不用横柱长度替代 Entry 逻辑。
Volume Profile 最有价值的不是告诉你“买还是卖”，而是告诉你“市场过去在哪里愿意成交，现在价值可能往哪里迁移”。
