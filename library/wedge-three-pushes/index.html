楔形与三浪推动

楔形真正有价值的不是两条收敛线，而是连续推动之后，边际推进是否衰减，以及原趋势在最后一次尝试后有没有真正失去结构控制。

预计阅读 11–14 分钟
核心结论三次推动只是衰竭观察框架，不是第三推完成就自动反转。
最大误区只要图形看起来像楔形就提前反手，忽略趋势仍可能继续加速。
执行原则第三推完成后进入观察，等失败延续、Reclaim、CHOCH/Micro Break 与首次回踩确认。

一、为什么常说“至少三次推动”

三次推动的意义，不在于数字本身，而在于给你一个比较“边际推进效率”的框架。第一次推动往往最干净，第二次继续创新高或新低，第三次如果仍能创新，但每次获得的新空间更小、回撤更深、K 线重叠更多，就说明原方向正在变得吃力。

如果第三次推动反而比前两次更快、更强、实体更大，那它可能根本不是衰竭，而是加速趋势。此时因为“已经三推”就反手，风险很高。

图 1：典型三次推动与边际推进衰减每次仍创新高，但新增空间越来越小
真正要比较的是每次推动的质量，而不是机械数“一、二、三”。

二、收敛线只是视觉辅助，形状不是交易信号

楔形经常伴随通道逐渐收窄，但“看起来像三角形”不等于趋势已经结束。强趋势同样可以在局部压缩后继续突破，尤其当高周期方向一致、外部目标尚未触达时。

因此更合理的流程是：楔形负责提醒你“趋势可能变脆”，结构负责告诉你“谁开始真正接管”。如果只有形状，没有失败延续和结构破坏，就不应该升级为反转执行。

更像衰竭楔形

三次推进仍创新高/低，但幅度递减、K 线重叠增加、回撤加深，末端还靠近外部流动性或高周期目标。

更像强趋势压缩

每次推进都迅速被接受，回撤浅，突破后立即跟随，趋势方向没有出现真正失败。

三、第三推之后，先等“失败延续”

所谓失败延续，是原趋势试图继续推进，但拿不到新的有效空间。比如顶部第三推后形成更低高点，但更重要的是卖方能否随后打出更低低点。如果更低高点之后价格只是横盘，最终又向上突破，那么所谓顶部结构根本没有完成。

这也是为什么“更低高点”不能单独当反转。一个结构点必须有后续结果，才能说明另一方真正拿走了控制权。

图 2：有 LH 不等于空头接管关键是 LH 之后能否推动出 LL
反转结构需要“连续后果”。单个 LH、单个 CHOCH 都只是证据的一部分。

四、从楔形观察到真正 Takeover

当第三推附近发生 Sweep，价格重新 Reclaim 关键区域，随后反向打破攻击方最近 pivot，这时证据开始从“衰竭”升级为“接管”。如果第一次 Retest Hold 仍然成立，才更接近可执行结构。

这条链路非常重要，因为它把“形态交易”变成“状态交易”：第三推不是下单点，而是让系统从 Trend Continuation 切到 Watch；Micro Break 进入 Probe/Wait；Retest Hold 才考虑 Main Entry。

图 3：Wedge → Sweep → Reclaim → Takeover从形态警报升级为结构确认
真正值得交易的不是“第三推”，而是第三推之后原趋势失败，并且另一方完成结构接管。

五、多周期怎么配合

H4/H1 的楔形更适合作为背景警报：原趋势可能进入后段。M15 用来判断方向是否真的开始改变，M5/M1 再寻找执行级结构。不要用 M1 的一个小楔形去对抗 H4 刚启动的强趋势。

相反，如果 H1 已经处于第三推末端，同时 M15 出现 Sweep/Reclaim，M5 又完成 Micro Break，这种多周期共振才有明显信息增量。

层级楔形的作用不应该做什么
H4 / H1判断趋势是否进入成熟/衰竭阶段直接用第三推市价反手
M15确认方向是否开始转变把每个小回撤都叫反转
M5 / M1寻找 Reclaim、Micro Break、Retest用微结构推翻大周期背景

六、常见误区

  • 机械数到第三推就做反转。
  • 只看收敛外形，不比较每次推动效率。
  • 把一个更低高点/更高低点直接当成接管完成。
  • 忽略高周期趋势目标和外部流动性位置。
  • 第三推后没有 Reclaim 或结构破坏，仍然强行逆势。
  • 在 M1 小楔形上对抗 H1/H4 强趋势。
楔形告诉你“原趋势可能正在变脆”；失败延续和结构接管，才告诉你“另一方真的开始控制”。
