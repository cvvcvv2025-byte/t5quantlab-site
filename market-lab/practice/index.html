按你熟悉的方法开始

不要求先掌握某一种体系，可以从当前正在使用的方法进入。

CLASSIC

布林带 / MACD / RSI / EMA

参数理解、背离、趋势环境、错误用法和多指标冲突。

PRICE ACTION

裸K / Pinbar / 吞没 / 二次拒绝

位置、第一次反应、第二次测试、确认与失效。

STRUCTURE

趋势 / BOS / CHOCH / Break-Retest

内部外部结构、突破接受、回踩与失败切换。

THEORY

波浪 / 缠论

推动、调整、分型、笔、线段、中枢和级别判断。

SMART MONEY

SMC / ICT / ICC

Liquidity、FVG、OB、MSS、OTE与时段。

VOLUME

成交量 / Volume Profile

POC、HVN、LVN、接受、拒绝和价值迁移。

多种题型

同一知识点可以通过不同方式训练，减少只会背定义的问题。

A

圈位置

在图上标出支撑、流动性、结构点、区间边界或关键区域。

B

判断 / 多选

当前更像延续、反转、震荡还是条件不足，并解释原因。

C

隐藏后续走势

先做选择，再展开真实后续，避免看答案倒推逻辑。

D

找错误

给一份已经画好的分析，找出错误标记、错误顺序或缺失条件。

E

对比题

同一段走势用布林带、裸K、SMC等不同方法分别解读。

F

规则理解

参数、计算、风险、入场与退出条件是否真正理解。

PRACTICE

持续扩充的基础题库

按主题、难度和题型逐步增加练习，方便反复训练同一类判断。
