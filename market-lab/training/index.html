统一训练流程

周期可以变化，但判断顺序保持一致。

1. Context

只看高周期：趋势、区间、位置、外部流动性。先写允许方向和禁止方向。

2. Location / Reaction

展开中周期：到达了哪里？出现Sweep、Acceptance、Reclaim、二次测试还是无反应？

3. Execution

低周期只回答是否出现Break、Retest、Micro Break、推进K以及明确失效位。

4. Management

Entry之后再讨论T1、减仓、BE和Runner，不允许事后把管理规则改成最漂亮路径。

5. Future + Review

最后展开真实后续，并把错误分类成背景、位置、执行、风险或程序实现。

训练错误分类

CONTEXT ERROR

背景错

把回撤当反转、把区间当趋势、让低周期推翻高周期职责。

LOCATION ERROR

位置错

在区间中部、扩张末端或目标空间不足的位置追单。

EXECUTION ERROR

时机错

Sweep当Entry、影线破位当BOS、没等Retest就追。

RISK ERROR

风险错

失效位不清、SL过窄/过宽、目标空间和风险不匹配。

HINDSIGHT ERROR

后见之明

因为后面涨跌了，反推当时“明明应该知道”。

PROGRAM ERROR

程序错

规则本身合理，但状态机、去重、减仓或SL修改没有真实执行。
