CONTEXT → LOCATION → REACTION → EXECUTION → TARGET

到达流动性，不等于自动反转。

同一个前高、前低、EQH/EQL或外部流动性，被扫以后可能反转，也可能被市场接受后继续突破。框架必须允许两种路径竞争，而不是预设答案。

CONTEXT

背景

H1/H4结构、波动环境、趋势年龄、主要外部流动性和当前是否处于扩张/压缩。

LOCATION

位置

多周期流动性、FVG、OB、前高前低、成交量节点和其他可解释AOI。

REACTION

反应

观察扫过、拒绝、Reclaim、实体接受、推动效率，而不是仅凭“碰到位置”下单。

EXECUTION

执行

根据后续行为进入Sweep-Reversal或Break-Acceptance-Retest；必要时两者自动切换。

TARGET

目标

目标来自下一层流动性、结构高低点、FVG/失衡或扩展区，不为了漂亮RR随意指定。

路径A：Sweep-Reversal

价格先扫过关键流动性，再收回并证明突破没有被接受。

Sweep

价格越过前高/前低/EQH/EQL或其他流动性节点。

Reclaim

实体重新回到关键位内侧，说明外侧价格没有形成稳定接受。

Takeover

突破攻击者Pivot或形成明确Micro Break，证明反向一侧开始接管。

First Retest / Immediate Entry

根据策略选择第一次回踩守住再进，或在Micro Break后直接执行；两种方案必须分别统计。

路径B：Break-Acceptance-Retest

如果扫过后不是Reclaim，而是持续接受在关键位外侧，就不应继续固执等待反转。

Break

实体突破关键流动性区域，而不是只有影线。

Acceptance

后续K线继续在外侧成交，回不到原区间，说明市场开始重新定价。

Retest

第一次回踩原突破区域并守住；如果重新深度收回，则Break路径失效并可能切回Sweep-Reversal观察。

Continuation

顺突破方向执行，并把失效位放在“接受被否定”的位置。

为什么自动切换比“永远反转”更重要

观察框架动作
扫过后快速收回进入反转观察，不立即下单
收回后又重新在外侧接受取消反转，切换Break-Retest
突破接受后第一次回踩守住顺突破方向执行
突破后深度重新收回原区间Break路径失效，重新评估Sweep-Reversal
研究：Sweep → Reclaim → Takeover学习：Break & Retest多周期框架
该框架的目标是减少“看到流动性就默认反转”的单向偏见。最终是否有效仍需要历史逐笔、账户级与前向验证。
