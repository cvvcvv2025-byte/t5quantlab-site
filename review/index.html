Trade Review

把自己的真实交易，变成下一轮训练数据。

上传做单截图和进场信息。系统不只解释行情，而是判断你这笔到底错在 Context、Location、Entry 还是 Management。

＋
上传交易截图支持 MT5 / TradingView方向、Entry、入场时间必填；SL / TP 可选
MVP Input

第一版不需要接 MT5 API

先验证“截图诊断是否真的让用户觉得有价值”。输入保持极简：截图 + Buy/Sell + Entry + 时间。

  • 识别图表周期与可见结构
  • 判断是否靠近关键流动性
  • 检查是否存在 Sweep / Reclaim / BOS / CHOCH
  • 分析是否提前、追单、震荡中间执行
  • 检查 SL / TP 是否与失效和目标逻辑匹配
