T5 Range Boundary

震荡不是随处反向交易。只有区间边界足够清晰、越界后出现拒绝或收回，才有值得执行的回归路径；区间中部没有位置优势。

查看产品方向返回产品矩阵

先定义边界，再讨论信号

这款产品不会用震荡指标超买超卖替代价格位置。

01 · RANGE QUALITY

确认区间有效

要求上下边界被多次响应、区间宽度足以覆盖成本，并排除已经单边扩张的结构。

02 · EDGE REACTION

等待边界拒绝

关注扫出后收回、二次拒绝或微结构接管，而不是价格第一次碰到边界就猜反转。

03 · RETURN PATH

确认回归空间

入场前必须保留指向区间内部的足够空间，目标优先看中轴与对侧流动性。

HARD FILTERS

明确不做什么

  • 不在区间中部开仓
  • 不在边界首次触碰时盲目反向
  • 不对已经形成接受的真突破逆势加仓
  • 不靠扩大止损维持错误的区间假设
PLANNED ROLE

在产品矩阵中的位置

当趋势扩张条件不足，但市场仍维持清晰横向边界时，它负责处理边界回归；一旦突破被市场接受，控制权交回趋势类策略。

产品规划：此页公开的是策略边界，不是已交付版本。正式发布时才会提供版本号、验证数据、适用参数与下载入口。
自动化交易存在亏损风险；任何区间都有可能演变成趋势突破。
