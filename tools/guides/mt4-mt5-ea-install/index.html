EA“挂上图表”只是第一步，真正要确认的是它有没有获得正确的运行权限。

很多“EA不下单”并不是算法问题，而是文件位置、编译、自动交易开关、品种名称、Magic Number、StopLevel、最小手数或网络环境出了问题。

安装顺序

1. 打开数据文件夹

MT4/MT5：文件 → 打开数据文件夹。不要凭Finder/资源管理器猜安装目录。

2. 放到正确目录

EA放在 MQL4/Experts 或 MQL5/Experts。源码是 .mq4/.mq5；编译产物是 .ex4/.ex5。

3. MetaEditor编译

源码需要在MetaEditor里编译。0 error只是“能编译”，不是“策略正确”。Warning也应逐项确认。

4. 回到终端加载

刷新导航器或重启终端，把EA拖到正确品种/周期图表。

5. 打开自动交易权限

MT4检查AutoTrading和EA属性“允许自动交易”；MT5检查Algo Trading以及程序属性权限。

同一账户运行多个EA

MAGIC

Magic Number必须隔离

不同EA至少使用不同Magic；更严格时还应同时区分Symbol、策略ID和SetupID。

POSITION

先确认Hedging / Netting

MT5账户模式会改变同品种多策略共存方式。Netting账户尤其不能假设每个EA都有独立Position。

RISK

账户级风险要合并

单个EA风险正常，不代表多个EA同时开仓后总风险仍正常。

上线前最少做一次故障演练

  • 终端重启后，已有持仓状态能否恢复。
  • 网络断开再恢复后，是否重复下单。
  • 订单被经纪商拒绝时，是否记录错误而不是死循环重试。
  • T1部分平仓后重启，Runner是否仍保持正确SL。
  • 两个图表同时加载EA，Magic是否冲突。
  • 邮箱/手机提醒是否只在正式事件触发。
