自定义指标装不上，先检查目录和编译，不要反复复制文件。

MT4/MT5自定义指标最常见的问题是放错数据目录、源码未编译、导航器未刷新、指标仅支持特定周期，或者旧图形对象没有清理。

标准安装流程

1. 文件 → 打开数据文件夹

必须从正在使用的MT终端打开对应数据目录。电脑可能装了多个MT实例，路径并不相同。

2. 放入Indicators目录

MT4：MQL4/Indicators；MT5：MQL5/Indicators。不要把指标放到Experts或Scripts。

3. 源码需要编译

.mq4/.mq5用MetaEditor打开并编译；.ex4/.ex5本身是已编译文件。

4. 导航器刷新或重启

部分终端导航器可右键刷新；如果看不到，最稳妥是关闭终端再重新打开。

5. 拖到正确图表

确认品种、周期和参数，再观察Experts/Journal是否有初始化错误。

为什么“挂上了但什么都没显示”

TIMEFRAME

周期不支持

有些指标只在M1/M5或指定周期运行。先看参数与页面说明。

DATA

历史K线不足

多周期结构、ATR、Volume Profile等功能可能需要更多历史数据才能初始化。

OBJECT

对象在后台但不可见

颜色和图表背景相近、绘制在错误窗口、坐标异常，都可能造成“好像没显示”。

FILTER

条件未满足

有些工具只显示当前有效计划，不会为了证明自己工作而随时画东西。

ERROR

运行时错误

查看Experts/Journal日志，不要只凭主图判断。

VERSION

旧版对象残留

升级指标后若对象命名未版本隔离，旧线条可能和新版叠加，需要清理。

T5类指标特别要检查的显示问题

  • 只显示当前周期时，高周期历史AOI是否仍被错误保留。
  • 失效的Entry/SL/T1/T2对象是否及时删除。
  • 白底图时文字是否仍可读，面板是否遮挡K线。
  • 统计面板清零后，历史对象是否错误影响当日统计。
  • 扫流动性/观察状态是否错误触发邮件或手机提醒。
  • 切换周期后对象是否重复创建。
