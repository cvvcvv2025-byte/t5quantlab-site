SERIES · BAR STATE · SECURITY · BROKER EXECUTION

Pine和MQL运行模型不同，正确迁移必须先翻译“语义”，再翻译代码。

Pine天然按时间序列/Bar表达逻辑；MQL运行在终端事件、tick、订单和账户环境里。逐行照搬很容易得到历史看似一致、实盘行为不同的版本。

Pine概念MQL迁移风险
series与历史索引数组方向、当前Bar/已收盘Bar必须明确，避免off-by-one和未收盘重算
request.security高周期Bar对齐、未收盘HTF值、时区和缺口语义要重新定义
barstateTick内更新与Bar Close授权要分开，不能每个tick重复发信号
plot/line/boxMT对象生命周期、命名、删除和失效清理需要显式管理
strategy.entry/exitTV策略模拟器不等于真实经纪商订单；点差、滑点、StopLevel、部分成交都要处理
