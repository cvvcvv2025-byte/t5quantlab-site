Verified Builds

源码工作流

已有EA或指标时，不从零重写。

1. 免费本地体检

识别MT4/MT5/Pine、函数、参数、下单、管理、多周期、提醒、CSV和敏感信息；不上传、不调用OpenAI。

2. AI深度分析

付费后重建Entry、Exit、Risk、State和依赖关系。

3. 冻结修改范围

把本次修改与必须保持不变的逻辑分开，范围没确认就不生成修改版。

4. 完整源码 + CHANGELOG

输出可继续维护的完整文件，并记录Changed / Unchanged / Warnings。

5. 编译、审计、发布

编译通过只是起点；关键状态、参数说明和目标平台行为都必须复核。
