CONTEXT → LOCATION → REACTION → EXECUTION → TARGET

流动性到达后，不默认反转。

这个项目最重要的改动，是把“扫流动性就反向做”拆成两条互相竞争的路径：Sweep-Reversal 与 Break-Acceptance-Retest。工具只负责显示当前路径和失效，不替代规则本身。

CONTEXT

背景

H1/M15结构、趋势阶段、区间位置和可用方向。

LOCATION

位置

前高低、EQH/EQL、FVG/OB、外部/内部流动性与重要AOI。

REACTION

反应

Sweep、Reclaim、实体接受、二次测试失败等事件。

EXECUTION

执行

Micro Break、First Retest Hold、推进K与正式Entry授权。

TARGET

目标

内部/外部流动性、结构目标与T1/T2，不用固定美金目标替代市场结构。

SWITCH

路径切换

反转观察若随后形成外侧接受，则转Break-Retest；突破接受若深度Reclaim，则转Sweep-Reversal。

两条执行路径

PATH A

Sweep-Reversal

扫流动性 → 收回 → 反向接管 → 微结构确认 → Entry。最危险的错误是把“扫到”直接当“反转”。

PATH B

Break-Acceptance-Retest

实体突破 → 外侧接受 → 第一次回踩守住 → 顺突破方向执行。最危险的错误是忽略重新深度收回。
