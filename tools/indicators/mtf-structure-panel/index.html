RESEARCH SPEC · H1/H4 CONTEXT · M15 DIRECTION · M5/M1 EXECUTION

每个周期只回答一个问题，避免“5个周期一起投票”。

这个面板的目标不是显示更多信息，而是把高周期背景、中周期方向与低周期执行拆开，最后只在主图保留当前计划真正需要的区域和状态。

CONTEXT

H1 / H4

趋势阶段、区间边界、外部流动性、主要结构位置。只负责背景，不直接触发Entry。

DIRECTION

M15

当前Attack方向、Acceptance/Rejection、中级Break/Reclaim与局部价值迁移。

EXECUTION

M5 / M1

Probe / Wait / Main Entry、微结构Break、第一次Retest、推进K和正式Entry授权。

显示层原则
