v0.3.0：按周期独立计算和恢复

当前周期自己的信号

切到 M15 计算 M15 模型，切到 H1 计算 H1 模型。不同周期的方向、候选和参考位可能不同，不再把固定 M5 计划当作所有周期的计划。

切周期保留记录

EnableStateCache 默认开启，按品种、执行周期、背景周期和实例分别保存。返回后恢复对应记录，并按随后历史补算；切周期本身不是计划结束条件。已确认参考位保持冻结，直到原 SL 或 TP2 触及。

邮件标明来源周期

邮件标题带 M5、M15 或 H1 等执行周期，正文给出背景周期和计划建立时间。同一事件去重按周期隔离。要同时监测多个周期，请分别开图表加载。

高周期历史按实际可用柱数读取。历史尚未同步时保留保存记录并提示 HISTORY WAIT，随后继续重试；状态无法保存时提示 STATE SAVE ERROR。保存文件在终端 MQL4/Files 或 MQL5/Files，文件名以 T5Map030_ 开头；请保留文件。

候选、确认和结束仍要分清

候选或“回踩完成”仍未确认，可能因背景变化、二次回踩、区域失效或超时取消，不保证走到候选 SL。浅色失效线标注本周期的收盘判定和价格；它与 SL 参考位不同。

确认后冻结参考价、SL、TP1、TP2，TP1 触及后继续跟踪。取消后保留本次原因、时间和参考位，不用上一笔 TP2 代替本次结果。历史柱同时覆盖 SL 与目标时，OHLC 无法证明先后，可能标记“顺序未知”。

图表计划结束不表示实际订单平仓。本指标不读取或管理账户持仓，不发送交易指令。历史补算不能恢复缺失的逐 tick 先后。

安装与使用设置

安装指标

  1. 解压专属包，将 EX4 放入 MQL4/Experts、EX5 放入 MQL5/Experts；导航器刷新后，在新的空白图表加载。首次允许 WebRequest 访问 https://t5quantlab.com。本程序仅显示图表，无需开启算法交易或DLL，不要替换已有交易EA。
  2. 选择想观察的图表周期，保持 EnableStateCache=true。KeepEndedPlans=true、PlanHistoryMarks 用于结束记录显示。
  3. 邮件先在终端“工具 → 选项 → 邮件”配置并测试，再将 EnableEmailAlerts=true；默认关闭。
  4. 同时收取多个周期提醒时，分别开 M5、M15、H1 等图表加载。首次加载或切周期不补发历史邮件；核对邮件周期和计划建立时间。

中文显示与邮件

MT4 中文字形嵌入 EX4，无需另装字体；中文位图标签的悬浮提示使用通用英文。MT5 保留中文文本和高 DPI 显示。邮件发送请求成功不保证送达，终端须在线；失败查看 Experts 日志，不自动重发当前事件。

记录保存

旧版没有保存的状态只能根据可用历史重建。删除状态文件、历史修正或缺失数据会限制恢复。保存失败和历史未就绪会在面板提示，请核对当前状态。
