安装与历史显示设置

  1. 在对应平台打开“文件 → 打开数据文件夹”：MT4放入MQL4 → Indicators（.ex4）；MT5放入MQL5 → Indicators（.ex5）。
  2. 刷新导航器或重启对应平台；从图表移除旧版，再加载v0.2.5。
  3. 确保H1和M5历史已加载；模型固定使用H1/M5，切换图表显示周期不改变模型。
  4. KeepEndedPlans=true开启结束记录；PlanHistoryMarks默认4，可选0—6。

旧记录受HistoryBars历史窗口限制，不是无限永久保存。每次重载根据已收盘历史重建；同一根K线同时覆盖SL与目标时，OHLC无法证明先后顺序，可能标记“顺序未知”。本工具不是逐tick成交日志。为避免遮挡K线，部分文字可能隐藏，线条上的提示仍可查看。
