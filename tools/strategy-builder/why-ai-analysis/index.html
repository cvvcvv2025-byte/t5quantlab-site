什么情况免费体检就够

STRUCTURE CHECK

只想先知道源码里有什么

例如有没有多周期、持仓管理、邮件提醒、CSV、WebRequest、DLL或状态机。

RISK SCREEN

先排查明显风险

发现疑似Token、密码、账户字段、外部请求或交易结果检查不足迹象后，先清理再决定是否继续。

TRIAGE

判断是否值得继续投入

如果只是很小的显示层改动，未必需要进入完整AI深度分析。

什么情况值得进入AI深度分析

STATE

涉及状态机/持仓管理

例如T1减仓、推保本、Runner、重新授权、重启恢复，这些不能靠简单文本替换处理。

MIGRATION

MT4→MT5 或 Pine→MQL

运行模型、订单模型和数据语义不同，需要重建规则，不是逐行翻译。

FROZEN SCOPE

必须保持原算法不变

先重建Entry/Exit/Risk/State，再明确只改指定部分，降低“修一个地方坏另一个地方”的概率。
